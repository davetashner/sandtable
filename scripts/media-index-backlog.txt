# Pictures the app cannot render, and why this file exists (sand-shn.16).
#
# `content/shared/media/index.json` is what the app reads; `npm run media`
# writes it from the `media.json` manifests, and needs the image binaries to do
# it — they are git-ignored and live only in a checkout that has fetched them
# from the assets bucket (decision 0004). The manifests grew by 49 between
# PR #89 and now; the index did not.
#
# The validator reads the manifests, so content citing these ids passes every
# gate. The app reads the index, so these 49 pictures silently do not render.
# Section 6 of scripts/check-content.sh is the gate that catches that drift from
# here on, and this file is the one-time allowance for the drift that already
# happened: without it the new gate would fail on `main` and block every PR for
# a bug no PR introduced.
#
# To remove it, in a checkout that holds the binaries:
#   npm run media                 # regenerate the index
#   npm run media -- --upload     # these images' derivatives may never have
#                                 # been synced either; the index alone is not
#                                 # enough if the bucket has no file to serve
# then commit the index, delete this file, and drop the last argument from the
# `check_index media …` call in scripts/check-content.sh. The gate refuses a
# line for an id the index already covers, so it cannot be left behind quietly.
