# Documents quoted before the receipt rule existed, and why this file is here
# (sand-23b.57.1, ADR 0021).
#
# Every `Document.excerpt` in this repository is a quotation and now needs a
# verification receipt: retrieved text with the quoted passage sitting inside
# it, so that a reviewer — or `npm run receipts -- --fetch` — can see the words
# in place instead of taking an author's word for them. Twenty-two documents
# were written before that rule existed. Two of them were verified in the PR
# that added the rule (the Hawaii operation order against the HyperWar
# transcription of Japanese Monograph 97, and the Schlieffen memorandum against
# the BSB transcription); these twenty were not, and without this file the new
# gate would fail on `main` and block every PR for a debt no PR introduced.
# That is the same bargain, and the same shape of file, as
# scripts/media-index-backlog.txt.
#
# A line here is NOT a claim that the quotation is wrong. It is a claim that
# nobody has shown it is right, which is the honest state of a citation that
# predates its own check.
#
# To remove a line:
#   npm run receipts -- --capture <url> --find "<a phrase from the excerpt>"
# paste what it returns into content/receipts/<era>.json as the `context` of a
# receipt naming the document in `usedIn`, then delete the line. The validator
# refuses a line for a document that already has a receipt, so this file cannot
# quietly outlive the debt it stands for.
#
# Where the work cannot be opened from here at all — Gallica answers with a
# security check, the Reichsarchiv volumes and most of the Russian monographs
# are borrow-only — the answer is not a receipt and not a line here. It is to
# stop quoting the work and keep citing it, which is what docs/sources.md has
# always said and what the 1917 pack already does. Removing the excerpt removes
# the line.
